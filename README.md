# FraudShield — Real-Time AI Fraud Detection Platform

> 7-model ensemble fraud detection with explainable AI, fraud persona classification, and live risk orchestration.

## What It Does

FraudShield analyzes credit card transactions in real time and returns not just a fraud probability, but a full analyst-grade report: which fraud attack vector is being used, which past transactions influenced the decision, and a plain-English explanation generated by an LLM.

Most fraud systems say: **"Fraud probability: 0.91"**

FraudShield says: **"Synthetic Identity Fraud — fabricated identity, new card immediately used for high-value crypto purchase with no behavioral history. BLOCK and escalate."**

## Key Features

### 🎭 Fraud Persona Detection
Goes beyond probability — classifies the *type* of fraud attack:
- **Card Testing** — micro-transactions to validate stolen card before high-value purchase
- **Account Takeover** — legitimate card, behavioral deviation via new device / location jump
- **Synthetic Identity** — fabricated identity, new card with no history used immediately for high-value transactions
- **Money Mule / Laundering** — round amounts, transfer merchants, international routing patterns

### 🧠 Explainable AI
- **SHAP values** for every prediction — global feature importance + per-transaction waterfall charts
- **Attention heatmap** from the LSTM — visualizes which past transactions most influenced the current decision
- Color-coded attention grid: red = high influence, gray = low influence, blue = current transaction

### ⚖️ Risk Orchestration Engine
Weighted scoring across all 4 signal sources:
```
Final Score = 0.35×Ensemble + 0.25×LSTM + 0.20×Autoencoder + 0.20×Rules
```
Hard overrides for critical patterns (extreme amounts, triple-threat VPN+location+device, crypto+new card+international).

### 🗂️ Feature Store
Persistent card behavioral profiles in PostgreSQL — tracks avg spend, velocity, merchant diversity, location diversity across all historical transactions. LSTM uses real sequence history on repeat cards.

### 📝 LLM Analyst Reports
Groq (llama-3.3-70b) generates a structured analyst report for every transaction — verdict, key risk factors, model consensus, and a specific recommended action.

## Local Setup

```bash
# Clone
git clone https://github.com/devarth26/Fraud-Detection.git
cd Fraud-Detection

# Python environment
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Environment variables
cp .env.example .env
# Add your GROQ_API_KEY and DATABASE_URL

# Database (PostgreSQL)
createdb fraudshield
uvicorn api.main:app --reload --port 8000

# Frontend
cd frontend
npm install
npm run dev
```

## Dataset

[Kaggle Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) — 284,807 transactions, 492 fraud cases (0.17% fraud rate). Heavy class imbalance handled via SMOTE oversampling and class-weighted loss functions.
